# Project 4: Hash Table

A Python-based hash table implementation that stores, retrieves, and removes key-value pairs using a custom hashing function and nested dictionaries to handle hash collisions.

## Features

- Create a HashTable object with an empty collection.
- Generate hash values by summing the Unicode code points of each character in a key.
- Add key-value pairs to the hash table.
- Store key-value pairs using their computed hash values.
- Handle hash collisions by storing multiple key-value pairs in nested dictionaries.
- Remove specific key-value pairs without affecting other entries with the same hash.
- Look up values using their original keys.
- Return `None` when a key does not exist.
