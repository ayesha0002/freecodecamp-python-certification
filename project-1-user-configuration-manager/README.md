# Project 1: User Configuration Manager

## Overview
A Python-based User Configuration Manager developed as part of the freeCodeCamp Python Certification. This project allows users to manage configuration preferences through a dictionary.

## Features
- **Add Settings:** Add new key-value pairs to the configuration dictionary.
- **Update Settings:** Modify the values of existing settings.
- **Delete Settings:** Remove settings from the dictionary.
- **View Settings:** Display all current user preferences in a readable format.
- **Input Handling:** Convert keys and values to lowercase and handle existing or missing settings.

## Concepts Practiced
- Python functions
- Dictionaries and key-value pairs
- Conditional statements (`if/else`)
- String methods (`lower()`, `capitalize()`)
- Dictionary methods (`items()`)
- Dictionary operations (adding, updating, and deleting elements)
- String formatting and return statements

## Example

```python
settings = {
    'theme': 'dark',
    'language': 'english',
    'notifications': 'enabled'
}
```

Example output:

```text
Current User Settings:
Theme: dark
Language: english
Notifications: enabled
```
