# Project 3: Polygon Area Calculator

A Python-based shape calculator that uses object-oriented programming to represent rectangles and squares and perform geometric calculations.

## Features

- Create Rectangle objects with width and height.
- Create Square objects using a single side length.
- Update rectangle width and height.
- Update square dimensions while maintaining equal sides.
- Calculate area, perimeter, and diagonal.
- Generate a visual representation of shapes using asterisks.
- Calculate how many times one shape can fit inside another.
- Display readable object representations.

## Concepts Learned

- Object-Oriented Programming (OOP)
- Python classes and objects
- Constructors and instance attributes
- Inheritance and method overriding
- Parent class initialization using `super()`
- Instance methods
- String representation using `__str__`
- Mathematical calculations
- Loops and string manipulation
- Integer division
