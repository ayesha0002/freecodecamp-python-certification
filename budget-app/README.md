# Budget App

A Python-based budget tracking application that manages spending across different categories.

## Features
- Create budget categories.
- Deposit and withdraw funds.
- Check category balances.
- Transfer money between categories.
- Display transaction ledgers.
- Generate a spending percentage chart.

## Concepts Learned
- Object-Oriented Programming (OOP)
- Python classes and objects
- Constructors and instance attributes
- Lists and dictionaries
- Methods and conditional statements
- String formatting
- Loops and list comprehensions
- Basic calculations and data processing

## Technology
- Python 3
